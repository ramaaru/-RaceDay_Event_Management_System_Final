# -RaceDay_Event_Management_System_Final

RaceDay is a web-based event management system developed using C# and ASP.NET Core. The system is designed to support South African road-running, walking and cycling events by providing a platform where event Organisers can manage events and Participants can register, enrol and view their race results.

Part 3 extends the Part 2 Web API by introducing an ASP.NET Core MVC frontend that communicates with the existing API.

### Main Features

- User registration and login.
- Role-based access for Organisers and Participants.
- Organiser dashboard and event management.
- Event category management.
- Participant event enrolment.
- Enrolment status tracking.
- Race result entry and viewing.
- Participant profile management.
- Azure Blob Storage for event banners and profile pictures.
- Responsive interface using Bootstrap.
- Docker containerisation.
- Automated testing and GitHub Actions CI/CD.

### Technologies Used

- C#
- ASP.NET Core Web API
- ASP.NET Core MVC
- .NET 8
- Entity Framework Core
- Microsoft SQL Server
- Azure Blob Storage
- Bootstrap, HTML and CSS
- Docker
- GitHub Actions
- xUnit

### Project Objective

The objective of RaceDay is to automate event management by providing an integrated platform that simplifies event organisation, participant registration, enrolment management and race result tracking.
